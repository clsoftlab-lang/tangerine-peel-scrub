# 귤결 GyulGyeol — 제주 귤껍질 업사이클 스크럽 스토어 (데모)

버려지던 **제주 귤껍질을 업사이클한 저자극·미세플라스틱 프리·비건 페이스/바디 스크럽** 브랜드 커머스 데모 앱입니다. 빌드 과정 없이 순수 HTML + CSS + ES 모듈 JS 로 동작하며 GitHub Pages 에 그대로 배포됩니다.

## 무엇인가요

귤결(GyulGyeol)은 폐기되던 제주 노지귤·한라봉 껍질을 저온 분쇄해, 플라스틱 마이크로비드를 대신하는 생분해 스크럽 입자로 되살립니다. 이 저장소는 브랜드 커머스 경험 전체를 담은 **프론트엔드 데모 스토어**입니다.

- **브랜드 스토리** — 제주 귤껍질 업사이클, 미세플라스틱 프리, 비건, 순환 포장.
- **제품 카탈로그** — 용도(페이스/바디)·피부타입·향·가격 필터, 검색, 정렬(추천/가격/평점/리뷰).
- **제품 상세** — 성분, 사용법, 비건 / 미세플라스틱 프리 / 저자극 배지, 리뷰.
- **1분 피부타입 진단** → 규칙 기반 추천 + 추천 이유 표시.
- **장바구니 + 모의결제**, **정기구독**(10% 할인), **찜**.
- **지속가능성 섹션** — 되살린 귤껍질(g)·감귤 환산 실시간 임팩트 카운터.

## 피부타입 추천 엔진 동작 방식

[`js/recommender.js`](./js/recommender.js)의 순수·설명 가능한 규칙 기반 점수 계산입니다(머신러닝·네트워크 없음). 1분 설문은 피부타입, 사용 부위(페이스/바디/둘 다), 향·자극 민감도, 선호 향, 비건 선호, 제품당 예산을 수집하고 각 제품을 다음과 같이 채점합니다.

1. **피부타입 일치** — 제품이 내 피부타입 포함 시 **+35**
2. **사용 부위** — `둘 다` +8, 카테고리 일치 +20, 불일치 −12
3. **자극 민감도** — *높음*: 무향 +14, 저자극 배지 +10, 미세플라스틱프리 +4, 향 있으면 −8(허브 −4); *낮음*: 향 있으면 +4
4. **향 선호** — 정확히 일치 시 +12
5. **비건 선호** — 비건 제품 +6
6. **예산** — 초과 −20, 예산의 55% 이하로 저렴하면 +4
7. **평점** — 동점 정렬용 소수 가산(`평점 × 0.7`)

사용 부위가 `둘 다`이면 그리디 선택으로 상위 추천에 페이스·바디를 각각 최소 1개씩 포함합니다. 각 추천은 점수를 올린 이유를 함께 반환해 화면에 표시합니다. `check.mjs`에서 단위 테스트로 검증합니다(피부타입 일치, 둘 다 커버, 민감도 효과, 향·예산 효과).

## 🤖 AI 기능 (API 연동)

플러그러블 **AI 레이어**가 [`ai/`](./ai/)에 있습니다. **기본은 키·네트워크 없이 동작하는 결정적 한국어 목업**으로, 앱의 제품 데이터와 규칙 기반 추천 엔진을 그대로 재사용해 세 기능이 오프라인에서도 바로 동작합니다. 상단 내비의 **AI 상담**에서 확인하세요.

1. **AI 스킨케어 상담 챗봇** — 피부타입·고민을 입력하면 추천 엔진으로 스크럽을 추천합니다.
2. **피부타입 추천 설명** — 피부타입 특징과 추천 이유를 설명합니다.
3. **브랜드 스토리 / 제품 카피 생성** — 업사이클·친환경 가치를 강조한 마케팅 카피를 만듭니다.

모든 답변에는 **의학적·피부과적 진단이 아님**을 명시합니다.

### 실제 Claude 연동 (백엔드 프록시)

브라우저는 절대 키를 보지 않습니다. [`server/`](./server/)의 소형 Node 프록시가 공식 `@anthropic-ai/sdk`로 Claude 를 호출합니다.

```bash
cd server
cp .env.example .env      # .env 에 실제 키 입력 (git 제외)
npm install
npm start                 # POST /api/ai (기본 :8787)
```

그다음 [`ai/config.js`](./ai/config.js)에서 엔드포인트를 지정합니다.

```js
export const AI_ENDPOINT = "http://localhost:8787/api/ai";
```

- 모델: **`claude-opus-5`**, adaptive thinking, 브라우저로 스트리밍.
- `AI_ENDPOINT`가 비어 있으면(기본값, `check.mjs`가 검증) 앱은 목업 모드를 유지합니다.
- **키는 서버 사이드에만.** `ANTHROPIC_API_KEY`는 `server/.env`(git 제외)에만 두며 **브라우저·레포에는 절대** 두지 않습니다. `check.mjs`가 실제 키 형식을 스캔합니다.

## 로컬 실행

빌드·의존성 없음. ES 모듈은 `file://`이 아닌 `http://`가 필요하므로 폴더를 HTTP 로 서빙합니다.

```bash
python -m http.server 9005
# http://localhost:9005/ 접속
```

검증 실행(JSON 파싱, 전체 JS `node --check`, index 컨테이너, 데이터 무결성, 추천/장바구니 단위 테스트):

```bash
node check.mjs
```

```
index.html          # 앱 셸 + 내비 + 필수 컨테이너
styles.css          # 모바일 퍼스트, prefers-color-scheme 라이트/다크
app.js              # 라우터 + 뷰 + 인터랙션 (ES 모듈)
js/recommender.js   # 규칙 기반 피부타입 추천 (단위 테스트)
js/cart.js          # 장바구니/구독/업사이클 임팩트 계산 (순수 함수)
js/storage.js       # localStorage 래퍼 (try/catch + 초기화)
ai/config.js        # AI_ENDPOINT ("" = 목업 모드)
ai/ai.js            # askAI(): 한국어 목업(추천엔진 재사용) 또는 프록시 스트리밍
server/index.mjs    # 선택: Node 프록시 → Claude(@anthropic-ai/sdk), 키는 서버에만
server/package.json / server/.env.example / server/README.md
data/products.json  # 가상 제품 24개
data/content.json   # 브랜드 스토리·설문·지속가능성·FAQ
check.mjs           # 의존성 없는 CI 검증기 (AI 키 스캔 포함)
.github/workflows/ci.yml
README.md / README.ko.md / LICENSE / .gitignore
```

데모 수량: **제품 24개**, 2개 용도(페이스/바디), 5개 피부타입, 5개 향, 6문항 진단.

## ⚠️ 데모 모드 경계

**본 저장소는 데모용 프론트엔드입니다. 아래 경계를 반드시 확인하세요.**

- **모든 제품·브랜드·성분·가격·리뷰·평점·인증은 가상입니다.** 실제 제품이나 의학적·화장품적 효능 주장이 아닙니다.
- **결제와 정기구독은 모의(시뮬레이션)입니다.** 실제 청구·주문·배송은 이뤄지지 않습니다.
- **상태는 `localStorage`에 저장되며 실제 데이터베이스가 아닙니다.** 장바구니·찜·구독은 브라우저에만 남고, 초기화 버튼(⟲)이 있습니다.
- **계정·로그인이 없으며 개인정보(PII)를 수집·전송하지 않습니다.**
- **실제 서비스라면** 백엔드, 실제 카탈로그·재고, 실제 결제/구독 처리, 인증, 검증된 지속가능성·비건 인증이 추가됩니다.
- 피부 진단은 **규칙 기반 데모 추천이며 의학적·피부과적 진단이 아닙니다.**
